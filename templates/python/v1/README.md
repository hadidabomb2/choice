# Python Template Notes

This template demonstrates the decorator, simple factory, factory method, abstract factory, strategy, facade, flyweight, proxy, composite, bridge, adapter, builder, prototype, singleton, chain of responsibility, command, iterator, mediator, memento, observer, state, template method, and visitor patterns using only the Python standard library.

Includes:
- `decorator/perf.py` — decorator to measure time, memory, and locals created
- `factory/shape_factory.py` — simple factory example
- `factorymethod/notifications.py` — factory method example
- `abstractfactory/ui_factory.py` — abstract factory example
- `strategy/greeter_strategies.py` — strategy example
- `facade/greeting_facade.py` — facade example
- `flyweight/text_style_factory.py` — flyweight example
- `proxy/timed_proxy.py` — proxy example
- `composite/nodes.py` — composite example
- `bridge/formatters.py`, `bridge/notifiers.py` — bridge example
- `adapter/legacy_logger.py`, `adapter/logger_adapter.py` — adapter example
- `builder/http_request_builder.py` — builder example
- `prototype/document_prototype.py` — prototype example
- `singleton/app_config.py` — singleton example
- `chain/handlers.py` — chain of responsibility example
- `command/commands.py` — command example
- `iterator/collection.py` — iterator example
- `mediator/chat_mediator.py` — mediator example
- `memento/text_editor.py` — memento example
- `observer/event_bus.py` — observer example
- `state/states.py` — state example
- `templatemethod/report_generators.py` — template method example
- `visitor/nodes.py` — visitor example
- `app/main.py` — example usage

Run:
- `python app/main.py`

Style Notes:
- `app/main.py` keeps each pattern demo in a small, named function.
- Numeric literals are promoted to named constants for clarity.
