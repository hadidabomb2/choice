# Python Design Templates

This template package includes a comprehensive collection of 23 Gang of Four design patterns, all implemented in pure Python using only standard library features.

## What's Included

- **Design Patterns**: Comprehensive examples of all 23 classic GoF patterns (Creational, Structural, and Behavioral)
- **Entry Point**: `designtemplates/main.py` — runnable demo of all patterns
- **Standard Library Only**: No external dependencies

## Quick Start

```bash
python designtemplates/main.py
```

## Structure

- `designtemplates/` — All 23 patterns organized by category
  - `main.py` — Pattern demonstrations
  - Pattern modules (decorator, factory, strategy, etc.)

## Style Notes

- Each pattern demo is kept small and focused with descriptive function names
- Named constants replace numeric literals for clarity
- Pure Python with no external frameworks
