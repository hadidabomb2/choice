# Python Design Templates

This template package includes a comprehensive collection of 23 Gang of Four design patterns plus real-world case studies, all implemented in pure Python using only standard library features.

## What's Included

- **Design Patterns**: Comprehensive examples of all 23 classic GoF patterns (Creational, Structural, and Behavioral)
- **Case Studies**: Real-world applications including rate limiting, real-time stock tracking, payment processing, and notification services
- **Entry Point**: `designtemplates/main.py` — runnable demo of all patterns
- **Standard Library Only**: No external dependencies

## Quick Start

```bash
python designtemplates/main.py
```

## Structure

- `designtemplates/` — All patterns organized by type
- `designtemplates/main.py` — Main entry point with demonstrations
- Pattern modules contain concrete implementations

## Style Notes

- Each pattern demo is kept small and focused with descriptive function names
- Named constants replace numeric literals for clarity
- Pure Python with no external frameworks
